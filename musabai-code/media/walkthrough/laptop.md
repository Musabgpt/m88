# Use the laptop

MusabAI can use your Linux Mint laptop, like MusabAI on Android uses the phone:

- open apps and web pages, show notifications, change the volume, control media;
- read or write the clipboard, take screenshots (models with vision can look at them);
- list and focus windows, type text, press keys, click (needs `xdotool`, X11 session).

Every action that changes something asks first. Turn it off in MusabAI Settings → Agent.
