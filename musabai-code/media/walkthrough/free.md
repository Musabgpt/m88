# Free models, no account

MusabAI Code works out of the box with **free** models:

| Provider | Key | Notes |
|---|---|---|
| Kilo gateway (`kilo-auto/free` and other zero-price models) | none | the default |
| Groq, Google Gemini, OpenRouter, NVIDIA, Zhipu GLM, Mistral | free key | faster, more capacity |
| Ollama, LM Studio, llama.cpp | none | runs on your laptop, private, offline |
| AI Horde | none | text-only last resort |

When a provider is busy or rate-limited, MusabAI moves to the next free model on its own and keeps your progress.
Choose the model in the chat box or the status bar (**MusabAI: Select Model**).
