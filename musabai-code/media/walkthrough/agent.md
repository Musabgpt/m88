# Chat and Agent

- **Ctrl+L** opens the chat (with the selected code), **Ctrl+I** starts a new agent chat.
- Modes: **Agent** (edits files, runs commands, verifies), **Plan** (investigates and writes a plan, then *Build*), **Ask** (read-only answers), **Manual** (only the edits you ask for).
- **@** adds context: files, folders, symbols, git diffs, the terminal, problems, web search, docs URLs, rules, past chats.
- **/** runs commands: `/review`, `/commit`, `/pr`, `/fix-ci`, `/issue`, `/background`, `/rule`, `/mcp`…
- Paste screenshots into the chat for models that can see images.
