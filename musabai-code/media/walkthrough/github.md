# GitHub

- **Generate commit message**: the ✨ button in Source Control.
- **Create Pull Request**: pushes the branch and writes the title and description.
- **Bugbot**: reviews your branch, uncommitted changes or a pull request for real bugs; findings go to Problems and can be posted on the PR.
- **Fix a GitHub issue** and **Fix failing GitHub Actions** start the agent with the issue or the failing logs.
- **Background agents** work on their own git worktree; then review, apply or open a pull request.
