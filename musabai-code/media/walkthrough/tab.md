# Tab autocomplete

Ghost-text suggestions appear as you type; press **Tab** to accept, keep typing to ignore.

For the fastest suggestions:
- add a free **Codestral** key (MusabAI Settings → Free API keys), or
- run `ollama pull qwen2.5-coder:1.5b`.

Without either, Tab uses the free chat model (slower). Toggle Tab from the status bar.
