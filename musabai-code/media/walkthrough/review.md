# Review every change

The agent writes to your files right away so tests and the terminal see the new code.
Every change stays **pending** until you decide:

- green lines are new, hover the dashed line to see removed code;
- **Accept / Reject** per change (CodeLens) or per file (editor title), or all at once in the chat;
- **Restore checkpoint** on any of your messages puts every file back as it was before that request.
